Slots for items in the Ring Menu.

Valid range for items is 0x0-0xA. (0x0B is '?' Item)

RING_USABLE_ITEM_SLOT_12 is normally never used as there is only 11 real items.

The upper 4 bits of a value control the number of items you have.
The lower 4 bits control the type of item.

Item count is controlled like so:
0x20: 1
0x40: 2
0x60: 3
0x80: 4

The game does a bounds check to limit your amount to 4 items. However
the system will support as many as 7 items(by using the value 0xE0).

The upper 4 bits are ignored for infinite use items.

Because of a bug it is possible to have your item count roll over.
Normally going from 1 to 0 removes the item from the ring, but
if you somehow manage to get 0 of an item (IE: 0x01 = 0 Chocolate)
then you can use the item and instead of removing it from the ring
the game will roll the value over to 0xE0 and you will gain 7 items.
